# architecture/

**Purpose:** Records of reviews focused on overall system design — module boundaries, dependency direction, consistency with accepted ADRs, and whether new work fits the intended architecture.

**Contents:** Dated review files using [../../templates/review.md](../../templates/review.md), each covering a specific piece of work or a periodic architectural health check.

**When it should be used:** When a change affects module boundaries or cross-cutting structure, when reviewing a large feature before merge, or periodically to check the codebase hasn't drifted from its ADRs in [../../architecture-decisions/](../../architecture-decisions/).
