# backend/

**Purpose:** Records of reviews focused on server-side/application logic — business rule correctness, error handling, API contracts, and code quality in backend code.

**Contents:** Dated review files using [../../templates/review.md](../../templates/review.md).

**When it should be used:** Before merging backend changes of non-trivial size, and as part of the [../../implementation/module-checklist.md](../../implementation/module-checklist.md) for each module. Use [../../checklists/backend.md](../../checklists/backend.md) as the review checklist.
