# security/

**Purpose:** Records of security-focused reviews — authentication/authorization correctness, data exposure risks, input handling, and dependency vulnerabilities.

**Contents:** Dated review files using [../../templates/review.md](../../templates/review.md).

**When it should be used:** Before merging any change touching auth, tenancy, sensitive financial data, or external input handling; and as part of the [../../implementation/module-checklist.md](../../implementation/module-checklist.md) for every module. Use [../../checklists/security.md](../../checklists/security.md) as the review checklist.
