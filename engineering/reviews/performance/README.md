# performance/

**Purpose:** Records of reviews focused on performance — query plans, load behavior, N+1 patterns, and bottlenecks under realistic data volumes.

**Contents:** Dated review files using [../../templates/review.md](../../templates/review.md).

**When it should be used:** For performance-sensitive modules (reports, high-volume transaction paths) before release, or when a performance issue is investigated. Reference [../../checklists/release.md](../../checklists/release.md) which gates release on performance sign-off for sensitive areas.
