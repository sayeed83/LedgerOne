# frontend/

**Purpose:** Records of reviews focused on UI/client-side code — component structure, state management, accessibility, and user-facing behavior.

**Contents:** Dated review files using [../../templates/review.md](../../templates/review.md).

**When it should be used:** Before merging frontend changes of non-trivial size, and as part of the [../../implementation/module-checklist.md](../../implementation/module-checklist.md) for modules with a UI. Use [../../checklists/frontend.md](../../checklists/frontend.md) as the review checklist.
