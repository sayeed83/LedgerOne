# Module Template

**Purpose:** Blank template for scoping a new module before implementation begins.

**When it should be used:** Copy this file when starting a new module (e.g. a new file under a `prompts/` phase folder, or a planning doc) to ensure scope, dependencies, and success criteria are defined up front. Pair with [../implementation/module-checklist.md](../implementation/module-checklist.md) to track completion.

---

## Module: <Name>

### Goal
What business capability does this module provide?

### Scope
What's in scope for this module. What's explicitly out of scope.

### Dependencies
Which other modules/foundations must exist first.

### Domain Rules
Key business rules this module must enforce (reference [00_BUSINESS_RULES.md](../../00_BUSINESS_RULES.md)).

### API Surface
High-level list of endpoints/operations this module exposes (detail in [api.md](api.md)).

### Data Model
High-level entities and relationships (detail in [database.md](database.md)).

### Success Criteria
How we know this module is done — links to [../implementation/module-checklist.md](../implementation/module-checklist.md).
