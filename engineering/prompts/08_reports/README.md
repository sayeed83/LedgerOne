# 08_reports/

**Purpose:** Prompts for reporting and analytics — financial statements (P&L, balance sheet, cash flow), operational reports, and dashboards.

**Contents:** Prompt files scoped to reporting features (e.g. `00_financial_statements.md`, `01_operational_reports.md`, `02_dashboards.md`).

**When to use:** After the modules that generate the underlying data (accounting, inventory, sales, purchase, banking) are in place. Revisit when a new report or data cut is requested.
