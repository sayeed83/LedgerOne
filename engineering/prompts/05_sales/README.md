# 05_sales/

**Purpose:** Prompts for the sales module — customers, sales orders, invoices, and revenue recognition.

**Contents:** Prompt files scoped to sales features (e.g. `00_customers.md`, `01_sales_orders.md`, `02_invoices.md`).

**When to use:** When implementing or extending sales functionality, after accounting and inventory foundations exist since sales transactions post to the ledger and consume stock.
