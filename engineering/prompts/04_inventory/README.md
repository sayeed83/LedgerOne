# 04_inventory/

**Purpose:** Prompts for the inventory module — items/SKUs, stock levels, warehouses/locations, stock movements, and valuation.

**Contents:** Prompt files scoped to inventory features (e.g. `00_items.md`, `01_stock_movements.md`, `02_warehouses.md`).

**When to use:** When implementing or extending inventory functionality. Coordinate with [../03_accounting/](../03_accounting/) prompts where inventory valuation feeds the general ledger.
