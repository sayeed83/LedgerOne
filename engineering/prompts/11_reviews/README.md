# 11_reviews/

**Purpose:** Prompts used to drive AI-assisted code review sessions — the instructions given to an AI assistant to perform a review, as distinct from the review findings themselves.

**Contents:** Prompt files scoped to review types (e.g. `00_security_review.md`, `01_backend_review.md`, `02_database_review.md`).

**When to use:** When kicking off a structured AI-assisted code review. The resulting findings are recorded separately in [../../reviews/](../../reviews/), not here — this folder holds the instructions, not the output.
