# 10_refactoring/

**Purpose:** Prompts for refactors, cleanups, and technical-debt reduction that don't add new functionality.

**Contents:** Prompt files scoped to specific refactoring efforts (e.g. `00_dedupe_ledger_helpers.md`, `01_simplify_invoice_flow.md`), each noting the motivation and scope of the refactor.

**When to use:** When addressing technical debt, improving code quality, or restructuring existing code without changing behavior. Significant refactors that change architecture should also produce an ADR in [../../architecture-decisions/](../../architecture-decisions/).
