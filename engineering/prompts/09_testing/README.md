# 09_testing/

**Purpose:** Prompts for generating and maintaining automated tests — unit, integration, and end-to-end — and for defining overall test strategy.

**Contents:** Prompt files scoped to test generation and strategy (e.g. `00_test_strategy.md`, `01_unit_tests.md`, `02_integration_tests.md`).

**When to use:** Alongside or immediately after implementing a module, to generate its test coverage. Also used when defining or revising the project's overall testing approach.
