# 06_purchase/

**Purpose:** Prompts for the purchase module — vendors, purchase orders, bills, and accounts payable.

**Contents:** Prompt files scoped to purchase features (e.g. `00_vendors.md`, `01_purchase_orders.md`, `02_bills.md`).

**When to use:** When implementing or extending purchasing functionality, after accounting and inventory foundations exist since purchases post to the ledger and increase stock.
