# 00_setup/

**Purpose:** Prompts for initializing the project — repository scaffolding, tooling setup, environment configuration, dependency choices, and CI/CD bootstrapping.

**Contents:** Prompt files (e.g. `00_repo_scaffold.md`, `01_dev_environment.md`, `02_ci_pipeline.md`) describing the exact instructions given to an AI assistant to set up project infrastructure, plus notes on outcomes.

**When to use:** At the very start of the project, or when standing up a new environment (staging, new developer machine, new CI runner). Revisit when tooling changes significantly (e.g. package manager migration, new linting standard).
