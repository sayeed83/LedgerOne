# archive/

**Purpose:** Storage for prompts that have been fully executed and are no longer the current approach, kept for historical reference rather than deleted.

**Contents:** Retired prompt files, ideally kept under a subfolder mirroring their original numbered location (e.g. `archive/03_accounting/00_old_journal_entry_prompt.md`) so their original context is preserved.

**When to use:** Move a prompt here once its work has shipped or its approach has been superseded — for example, after a module is rebuilt with a different design. Do not delete superseded prompts; archiving preserves the reasoning trail for why current code looks the way it does.
