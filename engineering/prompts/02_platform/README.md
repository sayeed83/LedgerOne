# 02_platform/

**Purpose:** Prompts for cross-cutting platform concerns that support every business module — authentication/authorization, multi-tenancy, configuration management, logging/observability, and core infrastructure.

**Contents:** Prompt files for platform capabilities (e.g. `00_auth.md`, `01_tenancy.md`, `02_config.md`, `03_observability.md`).

**When to use:** After foundation work is in place and before module-specific business logic depends on these services. Revisit whenever a platform capability is extended (e.g. adding SSO, adding a new tenancy tier).
