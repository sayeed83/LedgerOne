# Milestones

**Purpose:** Concrete, dated targets that group related work from the [roadmap](roadmap.md) into shippable checkpoints (e.g. "MVP accounting core," "Sales module beta").

**Contents:** A list of milestones, each with a target date, the phases/modules it covers, and its completion criteria.

**When it should be used:** Update when a milestone is defined, its scope changes, or it is completed. Use to answer "what are we shipping and by when?" — as distinct from the roadmap's "what order are we building things in?"
