# Roadmap

**Purpose:** High-level, long-lived view of the order in which LedgerOne modules and capabilities are planned to be built. This is the "big picture" — coarser-grained than [milestones.md](milestones.md) and more stable than [current-phase.md](current-phase.md).

**Contents:** An ordered list of major modules/phases (mirroring the numbering in [../prompts/](../prompts/)), each with a one-line goal and status (Not Started / In Progress / Done).

**When it should be used:** Consult when planning what comes next at a macro level, or when a stakeholder asks "what's the overall plan?" Update when the module order or scope materially changes — not for day-to-day progress (use [current-phase.md](current-phase.md) for that).
